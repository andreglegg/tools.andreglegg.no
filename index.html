Tools that
make things

Two generators for game asset work, hosted as remote MCP servers. Nothing to install — point your client at a URL. This tree is generating in your browser right now; change it.

Connect it

One command. The server is public and needs no key.

claude mcp add --transport http treegen https://mcp.andreglegg.no/treegen

Works with any MCP client that speaks Streamable HTTP. Generated files come back as download links valid for 30 minutes, so a 600 KB mesh never lands in your model's context.
